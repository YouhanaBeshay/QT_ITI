# MultiMedia App
- A QT Multimedia App that allows you to play music, videos and Network radio stations.
## Features
- **Play audio files**:
  - From local storage (file dialog) for multiple files.
  - From ALL mounted USB drives (by scanning /media folder for ANY non duplicated Audio files ).
  - <small> No Bluetooth support for now</small>
- **Play videos**:
  - From local storage (file dialog) for multiple files.
  - From ALL mounted USB drives (by scanning /media folder for ANY non duplicated Video files). 
- **Play Network radio stations**:
  - By using the amazing open source API of [Radio Browser](https://radio-browser.info/)
  - User can search for radio stations by name or by tags.
